Como Configurar os Dispositivos para Usar Este DNS

Para que o bloqueio funcione nos computadores e celulares, configure o IP deste servidor como o DNS Primário:

🌐 No Roteador (Recomendado): Acesse o roteador da sua rede (ex: 192.168.1.1) → Configurações DHCP → Defina o DNS Primário com o IP deste servidor. Todos os dispositivos da rede serão protegidos automaticamente!
💻 No Windows: Configurações → Rede e Internet → Propriedades do Wi-Fi/Ethernet → Atribuição de DNS → Manual (IPv4) → DNS Preferencial = IP deste servidor.
🐧 No Linux: Edite o arquivo /etc/resolv.conf adicionando a linha nameserver IP_DO_SERVIDOR ou ajuste via NetworkManager.
